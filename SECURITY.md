# Security Policy

Found a vulnerability or a leaked credential? Report it privately. Give us time to ship a fix before you disclose anything publicly, and we will credit you in the advisory if you want.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## How to Report

Do **not** open a public GitHub issue. Use the private channel instead:

1. Open the [Security Advisories tab](https://github.com/tBeltty/smooth-prose/security/advisories).
2. Click **"Report a vulnerability"** and describe what you found, the affected files, and the steps to reproduce it.

Only the maintainers can read the advisory. We acknowledge receipt within 48 hours. A remediation timeline follows once we have confirmed the report.
